## Ringkasan Sistem

**TUMBUH UMKM** adalah sistem informasi berbasis web untuk pendataan, pengelompokan, dan rekomendasi program bantuan bagi Usaha Mikro, Kecil, dan Menengah (UMKM) di tingkat desa.

### Peran Pengguna

| Peran | Akses Utama |
|-------|-------------|
| **Pemilik UMKM** | Profil usaha, produk, kebutuhan & kendala, rekomendasi, riwayat pembinaan |
| **Petugas Desa** | Verifikasi UMKM, pendataan, program bantuan, tindak lanjut, laporan |
| **Kepala Desa** | Dashboard, pengelompokan, rekomendasi, laporan, persetujuan tindak lanjut |
